# Azure Database for PostgreSQL Flexible Server

> **Type:** Resource · **Scope:** shared (one server, one database per env) · **Name:** `pg-<project>-<random>` · **Stack:** `infra/shared`

A managed Postgres database. Azure handles patching and backups.

## Why we use it

Dagster keeps all of its operational state here: run history, event logs, schedules and
sensor state. It lives outside the cluster so state survives deleting AKS. The pipeline's data lives in
[ADLS](adls.md), not here.

## How it's used here

| Setting | Value | Why |
|---------|-------|-----|
| Version / SKU | 16, `B_Standard_B2s` (variables `pg_version`, `pg_sku_name`) | Burstable and cheap |
| Region | `centralus` (`pg_location`) | Burstable SKUs weren't available in `eastus2` |
| Storage | 32 GB | Minimum |
| HA / geo-backup | Off; 7-day backups | Cost |
| Network | Public with firewall rules `aks-egress` and `user-ip` | See [network access](../concepts/network-access.md) |
| Databases | `<project>_stage`, `<project>_prod` | One per environment |
| Auth | User `pgadmin`; password generated by Terraform and stored in [Key Vault](key-vault.md) as `pg-admin-password` | Entra auth is a future upgrade |

Helm points each release at its database (`postgresqlDatabase`) and requires TLS (`sslmode: require`).
The host name is `PG_FQDN` in `.env`.

## Key commands & files

```bash
az postgres flexible-server stop  --resource-group rg-dagster-shared --name "${PG_FQDN%%.*}"
az postgres flexible-server start --resource-group rg-dagster-shared --name "${PG_FQDN%%.*}"
just stop / just start
```

## Gotchas

- Azure **auto-restarts a stopped server after 7 days**. Stop it weekly or accept the cost.
- The server is in a different region from AKS, which adds a little latency and cross-region traffic.
- Both environments share one admin login. Moving to per-env roles is a hardening step.
- Firewall rules use the AKS egress IP, which can change after a cluster rebuild.

## Cost

About $25/month running, about $6 stopped (see [costs](../costs.md)).
